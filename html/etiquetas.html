Tipos de etiquetas en HTML

HTML (HyperText Markup Language) utiliza una variedad de etiquetas para estructurar y presentar contenido en la web. Estas etiquetas se pueden clasificar en
diferentes tipos según su función y propósito. A continuación, se describen algunos de los tipos más comunes de etiquetas en HTML:

1-Etiquetas de documentos

Las etiquetas de documentos fundamentales en HTML (HyperText Markup Language) son aquellas que estructuran el esqueleto básico de cualquier página web. Indican al navegador dónde empieza y termina el documento, qué tipo de documento es y dónde se encuentra la información para el navegador (metadatos) y el contenido visible. Tambien dan instrucciones que indican al navegador cómo mostrar diferentes elementos, como texto, imágenes o enlaces, al interpretar el código HTML. Las etiquetas principales de documentos en HTML son:

  • html

    La etiqueta <html> es la etiqueta raíz que envuelve todo el contenido de un documento HTML. Indica al navegador que el contenido es HTML. Contiene todo el contenido del documento HTML, excepto la declaración <!DOCTYPE>. A menudo se incluye el atributo lang para especificar el idioma principal del contenido.

  • head

    Define la cabecera del documento HTML; esta cabecera suele contener información sobre el documento que no se muestra directamente al usuario como, por ejemplo, el título de la ventana del navegador. Dentro de la cabecera.La etiqueta <head> contiene metadatos y enlaces a recursos externos, como hojas de estilo y scripts. No se muestra directamente en la página web. Dentro de <head> es posible encontrar: <title>: define el título de la página. Por lo general, el título aparece en la barra de título encima de la ventana.<link>: para vincular el sitio a hojas de estilo o iconos. Por ejemplo:<link rel="stylesheet" href="/style.css" type="text/css">.<style>: para colocar el estilo interno de la página; ya sea usando CSS u otros lenguajes similares. No es necesario colocarlo si se va a vincular a un archivo externo usando la etiqueta <link>.

  • body

    Define el contenido principal o cuerpo del documento. Esta es la parte del documento html que se muestra en el navegador; dentro de esta etiqueta pueden definirse propiedades comunes a toda la página, como color de fondo y márgenes. Dentro del cuerpo <body> es posible encontrar numerosas etiquetas. A continuación se indican algunas a modo de ejemplo: <article>: Representa una composición auto-contenida en un documento, página, una aplicación o en el sitio, que se destina a distribuir de forma independiente o re-utilizable. <h1> a <h6>: encabezados o títulos del documento con diferente relevancia. Entre otras.

2-Etiquetas de Meta Datos

Las etiquetas de metadatos en HTML son elementos que proporcionan información adicional sobre el documento HTML, pero que no se muestran directamente en la página web. Estos metadatos pueden incluir detalles como la codificación de caracteres, la descripción de la página, las palabras clave para los motores de búsqueda y enlaces a recursos externos como hojas de estilo y scripts. Las etiquetas de metadatos se colocan dentro del elemento <head> del documento HTML. Algunas de las etiquetas de metadatos más comunes incluyen:

  • meta

    La etiqueta <meta> se utiliza para proporcionar metadatos sobre el documento HTML, como la codificación de caracteres, la descripción de la página y las palabras clave para los motores de búsqueda. No tiene una etiqueta de cierre y se coloca dentro del elemento <head>. Algunos atributos comunes de la etiqueta <meta> incluyen: charset: especifica la codificación de caracteres del documento (por ejemplo, UTF-8).name y content: se utilizan juntos para definir metadatos específicos, como la descripción de la página o las palabras clave.

  • style

    La etiqueta <style> se utiliza para definir estilos CSS (Cascading Style Sheets) dentro de un documento HTML. Permite incluir reglas de estilo directamente en el archivo HTML, en lugar de vincular a un archivo CSS externo. La etiqueta <style> se coloca dentro del elemento <head> del documento HTML. Dentro de la etiqueta <style>, se pueden escribir reglas CSS que afectan la apariencia de los elementos HTML en la página web.

  • title

    La etiqueta <title> define el título del documento HTML. Este título se muestra en la barra de título del navegador o en la pestaña cuando la página está abierta. También es utilizado por los motores de búsqueda para mostrar el título de la página en los resultados de búsqueda. La etiqueta <title> se coloca dentro del elemento <head> del documento HTML y debe contener un texto descriptivo que refleje el contenido de la página.

  • base

    La etiqueta <base> se utiliza para especificar la URL base para todas las URLs relativas en un documento HTML. Esto significa que cualquier enlace o recurso que utilice una URL relativa se interpretará en relación con la URL base definida por esta etiqueta. La etiqueta <base> se coloca dentro del elemento <head> del documento HTML y solo puede haber una etiqueta <base> por documento. Tiene dos atributos principales: href, que define la URL base, y target, que especifica el destino predeterminado para los enlaces (por ejemplo, _blank para abrir en una nueva pestaña).

  • link

    La etiqueta <link> se utiliza para vincular recursos externos al documento HTML, como hojas de estilo CSS, iconos y otros archivos relacionados. No tiene una etiqueta de cierre y se coloca dentro del elemento <head> del documento HTML. Algunos atributos comunes de la etiqueta <link> incluyen: rel: especifica la relación entre el documento actual y el recurso vinculado (por ejemplo, "stylesheet" para hojas de estilo).href: define la URL del recurso vinculado.type: indica el tipo de contenido del recurso vinculado (por ejemplo, "text/css" para hojas de estilo CSS).

3-Etiquetas de Agrupacion

Las etiquetas de agrupación en HTML son elementos que se utilizan para organizar y estructurar el contenido dentro de un documento HTML. Estas etiquetas permiten agrupar varios elementos relacionados, facilitando la aplicación de estilos y la manipulación del contenido mediante CSS y JavaScript. Algunas de las etiquetas de agrupación más comunes incluyen:

  • p

    La etiqueta <p> se utiliza para definir un párrafo en un documento HTML. Representa un bloque de texto que generalmente contiene una o más oraciones relacionadas. La etiqueta <p> tiene una etiqueta de cierre correspondiente </p> y se utiliza para separar bloques de texto, proporcionando un espacio vertical entre ellos en la presentación visual de la página web.

  • hr

    La etiqueta <hr> se utiliza para insertar una línea horizontal en un documento HTML. Esta línea actúa como un separador visual entre secciones de contenido, ayudando a organizar y estructurar la información en la página web. La etiqueta <hr> no tiene una etiqueta de cierre y es un elemento vacío. Por defecto, la línea horizontal se muestra como una línea delgada que atraviesa el ancho completo del contenedor en el que se encuentra.

  • ul

    La etiqueta <ul> se utiliza para crear una lista desordenada en un documento HTML. Representa una colección de elementos de lista que no tienen un orden específico, y cada elemento de la lista se define utilizando la etiqueta <li>. La etiqueta <ul> tiene una etiqueta de cierre correspondiente </ul>. Por defecto, los elementos de una lista desordenada se muestran con viñetas (puntos) delante de cada elemento, aunque esto puede ser modificado mediante CSS.

  • div

    La etiqueta <div> se utiliza como un contenedor genérico para agrupar elementos HTML. No tiene un significado semántico específico, pero es útil para aplicar estilos CSS o para manipular grupos de elementos mediante JavaScript. La etiqueta <div> tiene una etiqueta de cierre correspondiente </div> y se utiliza comúnmente para estructurar el diseño de una página web.

  • figure

    La etiqueta <figure> se utiliza para encapsular contenido gráfico, como imágenes, ilustraciones, diagramas o fragmentos de código, junto con su leyenda o descripción. Proporciona una forma semántica de agrupar estos elementos relacionados, lo que facilita la comprensión del contenido tanto para los usuarios como para los motores de búsqueda. La etiqueta <figure> tiene una etiqueta de cierre correspondiente </figure> y suele ir acompañada de la etiqueta <figcaption> para proporcionar una leyenda o descripción del contenido gráfico.

  • figcaption

    La etiqueta <figcaption> se utiliza para proporcionar una leyenda o descripción para el contenido encapsulado dentro de la etiqueta <figure>. Esta etiqueta ayuda a contextualizar y explicar el contenido gráfico, como imágenes, ilustraciones o diagramas, que se encuentra dentro del elemento <figure>. La etiqueta <figcaption> tiene una etiqueta de cierre correspondiente </figcaption> y generalmente se coloca como el primer o último hijo del elemento <figure>.

4-Etiquetas Textuales

Las etiquetas textuales en HTML son elementos que se utilizan para dar formato y estructura al texto dentro de un documento HTML. Estas etiquetas permiten definir diferentes estilos y significados para el texto, mejorando la legibilidad y la presentación del contenido en la página web. Algunas de las etiquetas textuales más comunes incluyen:

  • a

    La etiqueta <a> se utiliza para crear enlaces (hipervínculos) en un documento HTML. Permite a los usuarios navegar de una página web a otra o a diferentes secciones dentro de la misma página. La etiqueta <a> tiene una etiqueta de cierre correspondiente </a> y utiliza el atributo href para especificar la URL del destino del enlace. Por ejemplo, <a href="https://www.ejemplo.com">Visitar Ejemplo</a> crea un enlace que lleva a los usuarios a "https://www.ejemplo.com" cuando hacen clic en el texto "Visitar Ejemplo".

  • span

    La etiqueta <span> se utiliza como un contenedor en línea para agrupar elementos de texto o aplicar estilos específicos a una parte del contenido dentro de un documento HTML. A diferencia de la etiqueta <div>, que es un contenedor de bloque, <span> no crea un salto de línea y se utiliza principalmente para aplicar estilos CSS o para manipular partes específicas del texto mediante JavaScript. La etiqueta <span> tiene una etiqueta de cierre correspondiente </span> y es útil cuando se desea resaltar o formatear una sección específica del texto sin afectar el flujo general del contenido.

  • sub

    La etiqueta <sub> se utiliza para definir texto que debe mostrarse como subíndice en un documento HTML. El texto dentro de la etiqueta <sub> se presenta ligeramente por debajo de la línea base del texto circundante, lo que es útil para representar fórmulas químicas, matemáticas o cualquier otro contenido que requiera un formato de subíndice. La etiqueta <sub> tiene una etiqueta de cierre correspondiente </sub>. Por ejemplo, en la fórmula química del agua, el "2" en H2O se escribiría como H<sub>2</sub>O.

  • sup

    La etiqueta <sup> se utiliza para definir texto que debe mostrarse como superíndice en un documento HTML. El texto dentro de la etiqueta <sup> se presenta ligeramente por encima de la línea base del texto circundante, lo que es útil para representar exponentes matemáticos, referencias bibliográficas o cualquier otro contenido que requiera un formato de superíndice. La etiqueta <sup> tiene una etiqueta de cierre correspondiente </sup>. Por ejemplo, en la notación matemática para el cuadrado de un número, el exponente "2" se escribiría como x<sup>2</sup>.

  • cite

    La etiqueta <cite> se utiliza para definir el título de una obra, como un libro, una película, un artículo o cualquier otra fuente de información. Esta etiqueta ayuda a identificar y resaltar las referencias a obras específicas dentro del contenido de un documento HTML. La etiqueta <cite> tiene una etiqueta de cierre correspondiente </cite> y generalmente se muestra en cursiva para diferenciarla del texto circundante. Por ejemplo, al citar un libro, se podría escribir: <cite>El Gran Gatsby</cite>.

5-Etiquetas Semanticas

Las etiquetas semánticas en HTML son elementos que proporcionan significado y estructura al contenido de una página web. Estas etiquetas ayudan a los navegadores y a los motores de búsqueda a comprender mejor la función y el propósito de diferentes partes del contenido, lo que mejora la accesibilidad y la optimización para motores de búsqueda (SEO). Algunas de las etiquetas semánticas más comunes incluyen:

  • nav

    La etiqueta <nav> se utiliza para definir una sección de navegación en un documento HTML. Representa un conjunto de enlaces de navegación que permiten a los usuarios moverse por diferentes partes del sitio web o acceder a otras páginas relacionadas. La etiqueta <nav> tiene una etiqueta de cierre correspondiente </nav> y se utiliza comúnmente para agrupar menús de navegación, barras laterales o cualquier otro conjunto de enlaces que faciliten la navegación dentro del sitio web.

  • section

    La etiqueta <span> se utiliza como un contenedor en línea para agrupar elementos de texto o aplicar estilos específicos a una parte del contenido dentro de un documento HTML. A diferencia de la etiqueta <div>, que es un contenedor de bloque, <span> no crea un salto de línea y se utiliza principalmente para aplicar estilos CSS o para manipular partes específicas del texto mediante JavaScript. La etiqueta <span> tiene una etiqueta de cierre correspondiente </span> y es útil cuando se desea resaltar o formatear una sección específica del texto sin afectar el flujo general del contenido.

  • footer

    La etiqueta <footer> se utiliza para definir el pie de página de un documento o una sección en HTML. Generalmente contiene información adicional, como derechos de autor, enlaces de navegación, información de contacto o cualquier otro contenido relevante que se desee incluir al final de la página o sección. La etiqueta <footer> tiene una etiqueta de cierre correspondiente </footer> y se coloca al final del contenido principal dentro del elemento <body> o dentro de una sección específica.
